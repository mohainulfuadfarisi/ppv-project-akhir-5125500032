# TugasKu — Pengelola Tugas Kuliah

## Deskripsi
TugasKu adalah aplikasi untuk membantu mahasiswa mencatat, mengelola, dan memantau tugas kuliah dalam satu tempat.

## Cara Menjalankan
1. Clone atau unduh repositori ini.
2. Buka folder proyek.
3. Jalankan file index.html melalui browser.
