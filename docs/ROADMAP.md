# Roadmap Project Akhir — TugasKu

| Sprint | Fokus dan fitur MVP | Deliverable dan bukti |
|---|---|---|
| P10 | Debug minimal 2 bug nyata pada pengelolaan tugas, validasi form, atau penyimpanan. Gunakan branch dan merge. | Catatan bug, bukti pengujian sebelum/sesudah, branch, merge, dan Git log. |
| P11 | Memecah kode menjadi minimal 3 modul ES, misalnya modul utama, pengelolaan tugas, dan penyimpanan. | Struktur modul di folder src/, aplikasi berjalan, dan Git log. |
| P12 | Membuat komponen reusable, memperkuat penanganan penyimpanan, serta mengintegrasikan satu pustaka UI dengan minimal 3 komponen. | Komponen reusable, ui-pustaka.js, DEPENDENCIES.md, README.md, CHANGELOG.md, dan tag v0.x. |
| P13 | Mematangkan konsep produk berdasarkan Tugas 7 dan mengevaluasi fitur MVP. | Konsep produk yang diperbarui, prioritas fitur, dan bukti implementasi. |
| P14 | Menyelesaikan pengujian dan menyiapkan demo akhir TugasKu. | Aplikasi final, screenshot tampilan HP dan laptop, serta bukti demo. |

## Pembaruan Mingguan
Roadmap diperbarui setiap minggu berdasarkan deliverable yang selesai, hasil pengujian, kendala, dan perubahan prioritas. Fitur yang belum selesai dipindahkan ke sprint berikutnya dengan alasan yang jelas.
